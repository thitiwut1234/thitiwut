### 💫 About Me

I am a passionate **Backend Developer & Software Engineer** based in Bangkok, Thailand. I specialize in building robust backend microservices, crafting elegant API architectures, and occasionally building highly interactive frontend experiences. 

I bridge the gap between structured enterprise systems (Java/OOP) and agile, modern serverless ecosystems (Node.js/Express). I also love exploring **AI-augmented development methodologies** and building workflows that maximize human-AI collaboration in software engineering.

- 🔭 **Current Focus:** Deepening expertise in enterprise Java, containerization, and serverless application designs.
- ⚙️ **Engineering Philosophy:** Clean code, robust test coverage, and scalable design patterns.
- 🤖 **AI & Automation:** Passionate about optimizing LLM coding agents using custom configurations and behaviors to streamline development.
- 🤝 **Collaboration:** I believe in sharing knowledge, working with positive teams, and delivering high-impact solutions.
